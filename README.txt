Snjallveggir 2046 - uppsetning a GitHub Pages
1. Bua til nytt repo a github.com (t.d. "skrifstofan-2046"), Public.
2. Add file > Upload files > drag inn ALLAR 3 skrarnar (index.html, three.min.js, OrbitControls.js). Commit.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. Eftir ~1 min er sidan a https://<notandanafn>.github.io/skrifstofan-2046/
Sidan virkar lika an nets, svo lengi sem skrarnar eru saman i moppu (opnadu index.html beint).
